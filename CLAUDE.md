# jains.es

Read README.md first — it covers the layout, how to add a post, and how deploys
work. This file is only the things that are easy to get wrong and expensive to
undo.

## Never

- **Never add a form, an input, a textarea or a newsletter signup.** The contact
  form was built and deliberately removed (commit c0f88b3). Contact is a
  WhatsApp link and a mailto, and that is the intended design — not an omission
  to fix.
- **Never edit anything under `blog/`, `public/sitemap.xml` or `public/feed.xml`.**
  All three are generated by `build/site.js` and are gitignored. Edit
  `content/posts/*.md` instead; the next build overwrites your changes.
- **Never edit the block between `<!-- generated:posts -->` and
  `<!-- /generated:posts -->` in `index.html`.** Same reason.
- **Never change a post's filename once it is live.** The filename is the URL.
  Renaming it silently 404s an indexed page.
- **Never add blog entries to `vite.config.js`.** It globs generated pages.
- **Never hand-edit DNS records for jains.es or www.jains.es.** Wrangler manages
  them through `routes` in `wrangler.jsonc`.
- **Never add a `main` script to `wrangler.jsonc`.** Without one the site is
  served purely from asset storage and uses no request quota.
- **Never set `workers_dev: true`.** It publishes an indexable duplicate origin.
- **Never commit `dist/`.**

## Adding a post

```bash
npm run post "The title"   # scaffolds content/posts/the-title.md, dated today
npm run build              # validates, generates, builds
```

The build **fails** on an unknown category, a malformed date, a duplicate slug,
or a source missing its tier. That is deliberate — fix the post, don't work
around the check.

Categories are fixed: `retail-tech`, `hrtech`, `edtech`. Adding a fourth means
a new topic page, a new URL, and a decision — ask before doing it.

## Writing standard

Inverted pyramid, senior practitioner audience, BBC/Reuters register. Each post
anchors on one dated development and ends in what a reader should do. Every
statistic carries a named source inline. A number with no traceable source gets
cut, not softened to "studies suggest".
