# Sessions

One file per day: the session plan, the angle, the horizon line, the starting
code, the five beats, the script, the wiki targets, the news, and the two
sections only the human fills — `## OUTCOME` and `## OPEN`.

**None of this is a page.** Nobody needs to know what was studied on a
Tuesday. The learning reaches readers folded into the topic page it belongs
to, at `/wiki/<slug>/`, and as the video. These files are committed because
the method is part of what is being published, not because they are content.

Written by `/day`. Read by `/newsletter`, by `/wiki`, and by `/sunday` for the
week's outcomes.
