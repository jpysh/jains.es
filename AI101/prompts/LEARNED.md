# Learned

One line per correction. Every prompt reads this file before it writes
anything. Appended automatically by any `again` command, and by hand whenever
something annoys you.

Format: `DATE | which prompt | what was wrong, and what to do instead.`

**This is the only file in the project allowed to grow without being pruned.**
It is the record of what the system got wrong and the reason it stops doing so.
Deleting a line means accepting the mistake will come back.

Keep each entry actionable. "The newsletter was boring" changes nothing.
"Section 2 items lead with the valuation — lead with what a reader pays or does
differently" changes tomorrow.
