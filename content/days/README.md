# Days

One file per edition: the newsletter, which is also the page at `/day/<n>/`
and the text pasted into Substack. Site first, so the canonical copy is the
one we own.

Written by `/newsletter` from that day's session file. Eight sections, 900 to
1,100 words, five minutes on a phone. Every concept links out to its wiki
page rather than being explained again.

`README.md` is skipped by the build; only dated files are editions.
